# VideoKnowledgeLab

VideoKnowledgeLab is a personal AI research project focused on evaluating and building practical pipelines for Korean video understanding.

## Project Goals

- Benchmark speech-to-text models for Korean audio
- Compare transcription accuracy, latency, and API cost
- Evaluate word-level and token-level timestamp quality
- Align speech transcripts with video timelines
- Benchmark multimodal models for video understanding
- Build a reproducible pipeline for extracting structured knowledge from long-form video

## Current Evaluation Areas

The project currently compares commercial and open-source speech recognition systems, including multilingual ASR models and cloud APIs. Evaluation focuses on Korean speech, domain-specific terminology, hallucination behavior, timestamp precision, processing speed, and cost efficiency.

## Cloud AI Usage

Cloud AI services may be used for model benchmarking, speech recognition, multimodal analysis, and timestamp-aligned knowledge extraction. Alibaba Cloud Model Studio is being evaluated for Fun-ASR and related AI models.
